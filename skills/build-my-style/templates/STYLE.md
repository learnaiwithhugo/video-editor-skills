## How to use this guide (read first)

**This is a set of guardrails, not a menu.** It fixes the LOOK: colours, font, how things move, how loud
sounds are, where text is safe, and what's banned. It does NOT limit what you make. For every line of a
script, ask what visual would explain THIS idea best, then design it fresh inside these rules. The proven
options below are examples of the look, not a list to pick from. Reuse one only when it's genuinely the
best fit, and mix things up across a video. (The first test edit made with a guide like this felt
"extremely restricted": it only used what was on the style page. Don't do that.)

When the person gives a note on an edit ("I don't like X"), write it in here as a dated rule or into
Rejected, so the next edit already knows.

## Ground rules

Starting rules every style begins with. Delete any the person reverses.

- No pop-in or scale-overshoot entrances. Things fade, glide up, or rise out of a blur.
- No black backgrounds behind visuals. Backgrounds rotate between the paper colour and the accent.
- No underlined words. Emphasis is colour, size or a shine.
- Real logos only: app icons from the actual apps, real screenshots taken after the page fully loads. Never redrawn logos.
- Groups of logos are tilted and overlapping, never a dead-straight uniform row.
- Push-ins on visuals are fast (under a second). Zooms on the face are long and smooth, with a short punch now and then.
- Visuals are big and well placed. No small graphic floating in empty space.
- Intro text has room to breathe. Never cramped lines.
- Sound effects are barely noticeable. If you can clearly hear one, it's too loud.
- Text stays inside Instagram's safe zone (below).
- Copy what reference reels DO (timing, motion, layout), never what they literally show.
